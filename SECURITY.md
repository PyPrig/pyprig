# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.2.x   | Yes       |

## Reporting a vulnerability

Report security issues privately through [GitHub Security Advisories](https://github.com/pyprig/pyprig/security/advisories/new).

Please do not open a public GitHub issue for a suspected vulnerability.

Include the PyPrig version, a short description of the impact, and steps to reproduce the problem if you have them. You should receive an acknowledgment within a few days.
